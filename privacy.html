Privacy policy

Last updated: 2 November 2026.

What it accesses

Through Google's drive.file permission, the tool can access only files and folders in the owner's Google Drive that it created itself or that the owner explicitly selected for it in Google's file picker. It cannot see or change any other file.

How the data is used

It uploads files that the owner generated on their own computer into the owner's own Drive folder, checks that they arrived intact, and updates one pointer file there. It does nothing else with Google user data.

Storage and sharing

Nothing is sent to the author, a server or any third party. The tool has no backend, no analytics and no advertising. It never changes sharing settings, so the files stay private to the owner's Google account. The sign-in token is kept only in the owner's own macOS Keychain.

Who can use it

Only its owner. It is not offered to other users.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

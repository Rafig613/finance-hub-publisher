Finance Hub publisher

Finance Hub publisher is a private, single-user tool. It runs on its owner's own computer and copies a summary file that the owner creates for themselves into a folder in the owner's own Google Drive, so the owner can read it on their other devices.

It is not offered to anyone else, has no sign-up, and is not a service. It asks Google only for the drive.file permission: it can see and change only the files it created itself or that the owner explicitly picked for it, not the rest of the Drive.
